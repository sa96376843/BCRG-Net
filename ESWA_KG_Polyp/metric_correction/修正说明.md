# HD95 / ASSD 修正说明

已将评估实现统一为论文定义的双向轮廓到轮廓距离。本机原始源码、结果和 PDF 保存在论文目录的 `surface_metric_fix_2026-10-28/before`；公开仓库提供修正后的源码、指标记录与本说明，不包含本机历史备份和原始数据文件。

## 主结果

表中数值为三个种子的均值 ± 样本标准差，单位为 64×64 图像像素。

| 方法 | 修正前 HD95 | 修正后 HD95 | 修正前 ASSD | 修正后 ASSD |
|---|---:|---:|---:|---:|
| U-Net | 12.338 ± 1.014 | 12.549 ± 1.022 | 3.520 ± 0.351 | 4.256 ± 0.426 |
| Skip-attention U-Net | 11.249 ± 1.208 | 11.457 ± 1.229 | 3.378 ± 0.402 | 4.105 ± 0.437 |
| Attention U-Net | 11.005 ± 0.324 | 11.240 ± 0.352 | 3.141 ± 0.168 | 3.882 ± 0.134 |
| UNet++ | 11.144 ± 0.498 | 11.345 ± 0.494 | 3.159 ± 0.217 | 3.846 ± 0.208 |
| Compact DeepLabV3+ | 10.587 ± 0.534 | 10.861 ± 0.534 | 3.097 ± 0.172 | 3.882 ± 0.167 |
| Wide U-Net | 10.591 ± 0.326 | 10.826 ± 0.388 | 2.978 ± 0.157 | 3.665 ± 0.165 |
| BCRG-Net | 10.344 ± 0.249 | 10.581 ± 0.246 | 3.068 ± 0.092 | 3.751 ± 0.085 |

BCRG-Net 的 HD95 仍为七种方法中最低，ASSD 仍为第二，Wide U-Net 的 ASSD 最低。距离数值增大；Dice、IoU、BTS、模型权重、阈值、划分和原始概率文件均未改变。

## 实现与记录恢复

轮廓由一次四邻域二值腐蚀取差得到。对两侧轮廓分别求到对侧轮廓的最近欧氏距离，合并全部距离（保留重复值），计算第 95 百分位与均值。空掩码仍按原协议排除，排除数不变。

41 次训练运行共保存了 6,109 幅 float16 概率图，而原评估用的是量化前概率。直接对 float16 数值阈值化会改变少数像素。因此重算脚本枚举每个量化区间内所有可能的原始阈值判定，并以归档的 Dice、IoU、旧 HD95、旧 ASSD 和 BTS 五项逐图指标核验，容差为 1e-10；不按修正后的分数选择候选。

6,107 幅的二值掩码可唯一恢复，保存在各运行的 `predictions_binary/`。另两幅存在多个兼容掩码：训练消融 graph_only 的 seed 29、Attention U-Net 的 seed 29，各一幅。两幅的所有候选 HD95 相同；ASSD 保留完整候选与上下界，JSON 的相应标量设为 null。两次运行的 ASSD 均值区间分别为 [3.680243553789365, 3.680258591305413] 和 [3.7575156939138763, 3.757547874734929]。所有兼容情况均给出相同的论文三位小数均值和标准差；排名也不受影响。原始 float32 概率并未恢复。

完整逐图核验表见 `surface_metric_recovery_audit.csv`，候选值和界限见对应 `per_image.json` / `result.json`，主表取整核验见 `main_comparison.json`。原指标另存于 `legacy_surface_metrics`，不参与新表统计。

## 冻结分支对照

“Full, inference α=0 / α=1”两项冻结对照没有完整的独立预测记录。表 2 保留 Dice、IoU、BTS，将这两行 HD95 标为“--”，图注说明原因。seed 13 的 α=0 与主实验所选融合和阈值完全相同，可复用其边界指标；其余五个模式运行的 HD95/ASSD 记为 null。它们不同于已完成重算的 graph_only 训练消融。

原始 `data/experiment_data_64x64.npz` 不是修正代码、主实验和训练消融所必需。若要补齐冻结对照，需要恢复能够复现旧预测的输入和运行环境。用现有公共原图与归档权重进行的复核未复现原预测，因此没有用这次推理替换原结果。

## 复核命令

在项目根目录、安装 requirements.txt 所需依赖后运行：

```text
python -m unittest discover -s src -p test_surface_metrics.py
python src/validate_surface_revision.py
python src/validate_revision.py
python src/revision_assets.py --tables-only
python src/recompute_archived_surfaces.py --source results --output metric_correction/recomputed_check
```

最后一条命令要求目标目录不存在。它读取保留的旧指标并重新枚举，不覆盖现有结果。今后 evaluate() 将同时保存未经概率量化影响的二值预测、阈值和概率；冻结分支分析也会保存各模式的逐图输出。
